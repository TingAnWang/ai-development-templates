**Delivery:** the tested viewer revision, saved check results, and receipt.

## Outcome

A user can review a target, correct an answer, save, resume in a fresh tab,
continue reviewing, and save again without losing decisions or history.

## Allowed work and preservation

Fix related defects in reviewing, answer changes, import/export, point selection,
the harness, and finalization. Preserve target membership, question meanings,
human decisions, and source identity. Use invented answers for tests.

There is no separate correction-iteration quota for these related repairs;
the assignment's shared resource budget still applies. In the original task,
the browser allowance was six launches, including failed probes. That number
belongs to the example and must be reconsidered for a new environment.

## Acceptance

| ID | Required condition | Evidence |
| --- | --- | --- |
| A1 | Correct review inputs | Expected targets/images; answers initially pending |
| A2 | Usable controls | Navigate, select, answer, and correct through real controls |
| A3 | Reliable save/resume | Download, import in a fresh tab, continue, and re-export |
| A4 | Integrity and isolation | Relevant refusal checks; separate reviewer and synthetic-session records |
| A5 | Tested delivery identity | Delivered site bytes match those exercised by the final checks |

Compare exported values, history, source identity, and reviewer separation
outside the browser. Retain meaningful failed runs and explain corrections.
A test count without those behaviors is insufficient.

## Stop and return

A blocker names a reproducible material consequence or missing essential
evidence. Return for a changed question meaning, expanded data access, unsafe
execution, or exceeded resources. Correct cheap reporting defects or disclose
them without inventing a functional failure.

Deliver the identified revision, acceptance evidence, failures, limits, and
next owner. The original next step was focused integration review before real
human use; this example does not authorize that use.
